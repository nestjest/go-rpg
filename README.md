# Go Dungeon

**Go Dungeon** — простая браузерная RPG-игра на Go для первого знакомства школьников с программированием.

Игрок управляет героем **Рыцарь Go**, сражается с монстром **Багозавром**, нажимает кнопки в браузере, а все правила игры считает сервер на Go.

## Идея игры

На экране есть герой, монстр, здоровье и три действия:

- **Атаковать** — нанести обычный урон.
- **Лечиться** — восстановить здоровье.
- **Суперудар** — попробовать нанести сильный удар, но можно промахнуться.

После каждого действия Go пересчитывает состояние игры:

- сколько урона получил монстр;
- сколько урона получил игрок;
- жив ли герой;
- побежден ли монстр;
- какое сообщение показать на экране.

## Почему это удобно для занятия

Игра маленькая, наглядная и легко меняется. Дети сразу видят результат своих правок в браузере.

| Идея программирования | Где это видно в игре |
| --- | --- |
| Переменные | HP, имена, урон, лечение |
| Условия | победа, поражение, критический удар |
| Случайность | случайный урон и шанс промаха |
| Функции | атака, лечение, суперудар |
| Сервер | Go обрабатывает кнопки |
| Браузер | показывает арену и персонажей |

Главная мысль для объяснения:

> Монстр, здоровье и правила боя живут не в браузере. Они живут внутри программы на Go.

## Структура проекта

```text
go-rpg/
├── main.go
├── templates/
│   └── index.html
└── static/
    └── style.css
```

Всего три основных файла:

- `main.go` — мозг игры и правила боя.
- `templates/index.html` — HTML-страница игры.
- `static/style.css` — внешний вид, персонажи и анимации.

## Как запустить

Нужен установленный Go.

В папке проекта выполните:

```bash
go run main.go
```

После запуска откройте в браузере:

```text
http://localhost:8080
```

## Что дети могут менять

Все самые понятные настройки находятся в `main.go`, в функции `newGame()`:

```go
playerName := "Рыцарь Go"
monsterName := "Багозавр"
playerHP := 100
monsterHP := 80
```

Можно менять:

- имя героя;
- имя монстра;
- здоровье героя;
- здоровье монстра.

Например:

```go
monsterHP := 300
```

Так обычный монстр превращается в босса.

## Урон

Обычная атака находится в функции `attack()`:

```go
damage := rand.IntN(20) + 5
```

Это значит:

> случайный урон от 5 до 24.

Можно сделать героя сильнее:

```go
damage := rand.IntN(40) + 10
```

## Критический удар

В игре есть шанс нанести двойной урон:

```go
if rand.IntN(100) < 20 {
	damage *= 2
}
```

Это значит:

> 20% шанс нанести двойной урон.

Можно изменить шанс:

```go
if rand.IntN(100) < 50 {
	damage *= 2
}
```

Теперь критический удар будет срабатывать в 50% случаев.

## Лечение

Лечение находится в функции `heal()`:

```go
heal := rand.IntN(15) + 5
```

Это значит:

> случайное лечение от 5 до 19 HP.

Можно сделать зелье сильнее:

```go
heal := rand.IntN(30) + 10
```

## Идеи заданий

Простые задания:

- переименовать героя;
- переименовать монстра;
- увеличить здоровье игрока;
- увеличить здоровье монстра;
- усилить обычную атаку;
- усилить лечение.

Средние задания:

- изменить шанс критического удара;
- сделать суперудар точнее;
- сделать монстра сильнее;
- изменить текст победы;
- изменить текст поражения.

Интересные задания:

- добавить кнопку “Магия”;
- добавить шанс промаха для обычной атаки;
- добавить случайные имена монстров;
- сделать уровень сложности;
- добавить магазин зелий;
- добавить кнопку “Побег”.

## Как проводить занятие

1. Запустите готовую игру.
2. Дайте детям поиграть 2–3 минуты.
3. Откройте файл `main.go`.
4. Покажите функцию `newGame()` и скажите: “Вот здесь находится мозг игры”.
5. Попросите детей изменить одно число или одно имя.
6. Перезапустите игру и покажите результат.

Лучше не начинать со слов “сегодня мы изучаем HTTP-сервер”.

Лучше сказать:

> У нас есть браузерная игра. Сейчас вы будете менять ее правила.

## Цель проекта

Цель **Go Dungeon** — показать, что программирование не абстрактное и скучное.

Одна измененная строка в Go сразу меняет поведение игры:

- монстр становится сильнее;
- герой лечится лучше;
- атака наносит больше урона;
- критический удар срабатывает чаще.

Это быстрый и понятный способ показать детям, что код управляет настоящей программой.
